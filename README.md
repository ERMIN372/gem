# B2B-витрина натуральных драгоценных камней

Одностраничный сайт-визитка для B2B-направления: ювелирные мастерские, кастомные ателье, закупщики и private orders.

## Стек

- Vite
- React + TypeScript
- Обычный CSS

## Запуск локально

```bash
npm install
npm run dev
```

После запуска откройте URL из консоли Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

## Где заменить контакты

Контакты и ссылки вынесены прямо в компонент `src/App.tsx`:

- Telegram placeholder: `@your_telegram` и ссылка `https://t.me/your_telegram`
- WhatsApp placeholder: `+7XXXXXXXXXX` и ссылка `https://wa.me/7XXXXXXXXXX`
- Email placeholder: `info@example.com` (используется в блоке контактов и в `mailto` формы)

Рекомендуется заменить эти значения перед публикацией.
